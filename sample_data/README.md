# Sample data

## sample-spectrum.csv

**Synthetic** stellar-like spectrum (not an observation): Planck continuum at
T_eff = 5772 K with gaussian absorption features at real H / Ca II / Na I line
wavelengths and seeded gaussian noise. Generated by
`server/scripts/generate_sample_spectrum.py` (seed 42); full generation
parameters in `sample-spectrum.meta.json`.

- License: CC0-1.0 (generated for this project).
- Import with provenance label **simulated**.
- Flux is relative (arbitrary units); absolute calibration is intentionally
  unknown, so the unknown-metadata flow is exercised end-to-end.

A real public-domain archive spectrum is planned for Stage 4 (decision D6),
with its source, access date, and license recorded at import.
